## Featured Project｜代表项目

### AdsAiPro

AdsAiPro is an AI-powered data analytics back office for advertising delivery, user operations, and agency/channel management.

AdsAiPro 是一套面向广告投放、用户运营和代理渠道管理的 AI 数据分析后台，支持：

- Business dashboards｜经营分析看板
- User and agency profiling｜用户与代理画像分析
- Channel AI analysis｜渠道 AI 分析
- Prompt template management｜Prompt 模板管理
- Advertising data synchronization｜广告数据源同步
- Spreadsheet and daily active data import｜表格与日活数据导入
